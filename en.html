Real-estate photo enhancement pipeline (2026, EvPro)

A PHP 8.4 / Laravel 12 module for batch processing of property photos. The decision to enhance is driven by nine measured frame features (brightness, contrast, shadows, highlights, noise, sharpness and others) collapsed into a single improvement score, with eleven guard checks on top that block publication when quality regresses. A cascade of "local processing → external generative model" draws an explicit line between what is done for free and what is paid for. Time and cost per unit of work were measured (23–28 s per frame locally; ~$3.10 for a batch of 62 frames through an external model), which moved the quality conversation with the business from impressions to money.

Laravel 12PHP 8.4

Project methodology JD+PARA (2026, open source)

My own system for running technical projects: Johnny.Decimal for numbering, P.A.R.A. for separating projects and resources, MOC for links — with rules that let both a human and AI agents work on the same documentation. What makes it more than an organiser: a question, a decision and a knowledge note are separate entities with mandatory fields. A question must state what changes once it is answered; a decision must list rejected alternatives and the condition for revisiting it; a finding must state what would refute it. That makes a project handover-ready: the next person (or agent) doesn't redo work already done. In use across nine of my own projects: 236 questions, 178 decisions, 141 knowledge notes. Starter kit published at github.com/Miniwe/jdpara.
